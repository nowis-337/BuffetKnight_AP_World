# Buffet Knight - Decadent Full Course - Archipelago Support

## Requirements
- Buffet Knight - Decadent Full Course on [Steam](https://store.steampowered.com/app/3072480/Buffet_Knight__Decadent_Full_Course/). Supported in Ver 1.1.1.2
- Buffet Knight AP World file (buffetknight.apworld) located in the Buffet Knight Steam installation folder "archipelago/buffetknight.apworld" or from [Github](https://github.com/nowis-337/BuffetKnight_AP_World/releases).

## Game Setup Instructions
Activate Buffet Knight Archipelago build by:
1. Right click on "Buffet Knight - Decadent Full Course" in the Steam library and select "Properties".
2. Under "Game Versions and Beta" select "Archipelago Branch".
3. Allow the game to update on launch.

Alternatively, you can just manually edit the text file located in the Buffet Knight Steam installation folder (archipelago/archipelago_mode.txt) to "active".

## Connecting to a Multiworld Game
After activating the Buffet Knight Archipelago build (see above):
1. Launch the game, select "New Game".
2. Select "Archipelago".
3. Enter the 5 digit room number of the hosted multiworld.
4. Enter your player name matching your corresponding YAML file of the hosted multiworld.
5. Wait for server connection and your game will begin!

## Archipelago Installation Instructions
This AP World is created for Archipelago version 0.6.4 or higher. You install the latest version of Archipelago [here](https://github.com/ArchipelagoMW/Archipelago/releases/latest).

Installing Buffet Knight as a custom world:
1. Start the Archipelago Launcher.
2. Under "Install APWorld", open the "buffetknight.apworld" file .

Alternatively, you can just copy the "buffetknight.apworld" file directly into the "custom_worlds" folder of the Archipelago installation folder.

Generating the Buffet Knight YAML file:
1. After installing Buffet Knight in the Archipelago Launcher, select "Generate Template Options".
2. "Buffet Knight.yaml" file will be generated in the Archieplago installation folder under "Player/Templates".
3. Open and edit the YAML file to customise your preferences.

A copy of the Buffet Knight YAML file is also included in Buffet Knight's Steam installation folder (archipelago/Buffet Knight.yaml).

## Generating a Multiworld Game
1. Gather all participating player YAML files and place them inside the "Players" in the Archipelago installation folder.
2. Start the Archipelago Launcher and select "Generate".
3. A zip file will be generated in the "output" folder within the Archipelago installation folder if successful.

## Hosting a Multiworld Game
1. Go to the "Host Game" page of Archipelago.gg [here](https://archipelago.gg/uploads).
2. Click "Upload File" and select the generated zip file in the Archipelago output folder (see above).
3. Click "Create New Room".
4. Take note of the 5-digit room number that players will need to refer to in order to connect.
